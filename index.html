Firebase Cloud Sync

یہاں اپنے Firebase Web App کی configuration محفوظ کرکے کلاؤڈ سنک فعال کریں۔ Firebase config آپ کے Firebase Console میں Project settings → Your apps → SDK setup and configuration میں ملتی ہے۔

آپ کا موجودہ Firebase پروجیکٹ پہلے سے درج ہے۔ Google Sign-in یا اپنے Admin Email/Password سے لاگ اِن کریں۔ Firestore میں ہر اکاؤنٹ کا ڈیٹا الگ محفوظ ہوگا۔
Firestore Security Rules (یہ کوڈ Firebase Console میں لگائیں)
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/coolHouseERP/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Firebase ابھی کنیکٹ نہیں ہے۔ لوکل ڈیٹا اس ڈیوائس پر محفوظ رہتا ہے۔
